# 予約システム 運用マニュアル（スタッフ向け）

管理画面: `https://diningbar-herlock.com/admin.html`（自分のメールアドレスとパスワードでログイン）

## 毎日やること

### 営業前
1. 管理画面の「今日」タブで本日の予約を確認（店長のLINEとカレンダーでも見られる）
2. 「仮受付」タブに赤いカードがあれば、**お客様に確認の電話**をする
   - 電話がついたら、席を選んで「電話済み・確定」をタップ → お客様に確定メールが自動送信される
   - 30名以上の団体は2Fを解放するか判断する
   - つながらない・不審な予約は「キャンセル」をタップ

### 営業中
- お客様が来店したら「今日」タブで「着席」をタップ（顧客リストの来店回数が自動で増える）
- 時間になっても来なければ電話 → 来ない場合は「来店なし」をタップ
- お会計が済んだら「お会計済み」をタップ

## 予約の受け方（重要・ダブルブッキング防止）

**ホットペッパーや電話で予約を受けたら、その場で必ず「登録」タブに入力する。**
これを忘れるとWeb予約と重なって席が足りなくなります。

1. 「登録」タブ → 受付元（ホットペッパー/電話）を選択
2. 日付・時間・人数・席（カウンター or テーブル・個室）を入力
3. 残り人数の表示を確認（⚠が出たら定員超過。席繰りできるか考えてから登録）
4. 名前・電話番号を入れて「登録する」

## キャンセル対応

- 前日18:00まで: お客様がメール内のURLから自分でキャンセルできる（何もしなくてよい）
- それ以降・電話でのキャンセル: 「一覧」タブで日付をタップ → 該当予約の「キャンセル」

## 休みの設定

「休業日」タブのカレンダーで日付をタップするだけ。
- 通常の日をタップ → 休業にする（不定休）
- 月曜（定休日）をタップ → 営業日にする（団体対応のとき）
- もう一度タップ → 元に戻す
設定すると予約フォームのカレンダーに即反映されます。

## 顧客リスト

- 「顧客」タブで名前・電話番号で検索。来店回数・最終来店・メモが見られる
- アレルギーや好みはメモに残す
- お客様から「情報を消してほしい」と言われたら: 削除ボタン → 名前を入力して確認 → 必要なら予約履歴の連絡先も匿名化

## 設定の変更

- 予約通知を受け取るメールアドレスの追加/削除: 「設定」タブ
- お客様からの返信を受けるアドレスの変更: 同じく「設定」タブ

## 週1回やること（店長）

## 困ったとき

- メールが届かない/通知が来ない → つるさんに連絡（notification_logで原因を調査できます）
- 画面がおかしい → 一度ログアウトして再ログイン。直らなければつるさんへ
- 緊急で予約を止めたい → 「休業日」タブで該当日を休業にすればWeb予約は即止まる
